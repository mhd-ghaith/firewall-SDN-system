About This Project

Software Defined Networking Firewall — Final Year Project

🛡️ Project Overview

This project implements a dynamic network firewall using Software Defined Networking principles. The system separates the control plane from the data plane, enabling real-time policy management through a web interface without requiring network restarts.

Security rules are pushed directly to OpenFlow switches via the Ryu controller, ensuring changes take effect instantly across the entire network. All rules and events are persisted in a SQLite database, surviving controller restarts.

⚙️ Technology Stack
SDN Controller Ryu Framework
Flow Protocol OpenFlow 1.3
Web Backend Flask · Python
Network Simulation Containernet · Docker
Database SQLite
✨ System Features
🔒
Dynamic Policy Management
Add, edit, and delete firewall rules in real time without restarting the controller.
⚡
OpenFlow Rule Enforcement
Rules are pushed to OVS switches as OpenFlow flow entries with configurable priorities.
📡
Traffic Monitoring
Real-time visibility into blocked traffic, active rules, and security events.
📋
Security Event Logging
Every rule change and blocked packet is recorded with a timestamp for auditing.
🛡️
Priority-Based Enforcement
Block rules (priority 200) always override Allow rules (priority 100) for the same traffic.
💾
Persistent Storage
SQLite database preserves all rules and logs across controller restarts.
🗺️ System Architecture
