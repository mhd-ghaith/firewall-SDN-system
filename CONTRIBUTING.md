# Contributing

Thank you for your interest in contributing to the SDN Firewall System.

## Reporting Issues

When reporting a problem, include:

- A clear description of the issue.
- Steps to reproduce it.
- Relevant error messages or logs.
- Your operating system and dependency versions.
- Expected and observed behavior.

Do not include passwords, secrets, or sensitive network information.

## Submitting Changes

1. Fork the repository.
2. Create a branch for your changes.
3. Implement and test your changes.
4. Update documentation where necessary.
5. Submit a pull request explaining the change and its validation.

## Testing

Test network-related changes in a controlled environment before submitting them.

Document the test procedure and observed results where possible.
